# Play Spark — Decision Records

Use this directory for decisions that materially affect architecture, dependencies, data modelling, security, privacy, or deployment.

## Naming

Use sequential names:

```text
0001-client-routing.md
0002-password-hashing.md
```

Copy `0000-template.md`, assign the next number, and replace the example content. Keep records concise and describe the decision that was actually made.

## Statuses

- `Proposed`: under discussion and not yet approved.
- `Accepted`: approved and active.
- `Superseded`: replaced by a later decision record.
- `Rejected`: considered and intentionally not selected.

When replacing a decision, link the old and new records in both directions.
